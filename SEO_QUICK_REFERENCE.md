# SEO Quick Reference - Remaining Pages

Complete SEO setup for these pages by copying and pasting the code below.

## Quote Page (`src/pages/Quote.tsx`)

Add to imports:
```tsx
import { useSEO } from '@/hooks/use-seo';
```

Add at start of component:
```tsx
useSEO({
  title: 'Get a Quote | Custom Web Development & IT Services',
  description: 'Request a custom quote for your web development, mobile app, or IT project. Get pricing tailored to your specific needs from Connect Sierra Leone.',
  keywords: 'quote, pricing estimate, web development quote, project quotation',
  canonical: 'https://connect-sierraleone.com/quote',
  ogUrl: 'https://connect-sierraleone.com/quote',
  type: 'website',
});
```
